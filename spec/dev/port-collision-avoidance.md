# Port Collision Avoidance

Project services avoid conflicting binds across concurrently active projects. Useful addresses remain visible with the processes that own them, not in a separate ports dashboard.

- Detect conflicts before or during service startup.
- Identify the conflicting project and process.
- Offer a clear recoverable resolution.
