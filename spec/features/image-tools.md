# Image Previews And Generation

Pi renders inline previews whenever images are pasted, read, attached, or generated.

- Keep source, path, prompt, dimensions, and generating tool attributable.
- Implement Codex-compatible image generation in Pi.
- Allow opening the full image or sending it into review and editor flows.
- Preserve a clear fallback when inline graphics are unavailable.
