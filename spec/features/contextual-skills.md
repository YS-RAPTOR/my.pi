# Contextual Skills

Available skills adapt to the current project, language, system, and work context. Users can explicitly attach supported files, repositories, packages, or command results as references.

- Show why each contextual skill is available.
- Require approval before a skill runs a command.
- Include reference results visibly in agent context.
- skills also can run commands in them!
