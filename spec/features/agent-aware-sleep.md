# Agent-Aware Sleep

Active agents and managed services inhibit system suspend, hibernation, and network loss while showing what is keeping the machine awake.

- Allow screen locking, dimming, and display power-off.
- Keep execution and network connectivity available.
- Release inhibition when all relevant work settles.
