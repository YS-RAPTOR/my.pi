# Reference Manager

A `reference` command and agent skill manage external material used during development.

- Accept repositories, packages, URLs, documents, and local paths.
- Download sources and record their origin, revision, description, and local path.
- Reuse existing local copies instead of downloading duplicates.
- Search and attach selected content to agent context.
- Keep exploratory references distinct from adopted dependencies.
- Allow explicit refresh and removal.
