# Background Computer Use

Each development Hyprland workspace can have a separate background Hyprland workspace where its agent performs computer-use tasks without controlling normal user workspaces.

- Make the owning Hyprland workspace visible.
- Separate browser, input, and captured output.
- Require approval for sensitive actions.
- Control pointer, keyboard, scrolling, focus, windows, and clipboard inside the background workspace.
- Capture screenshots and return visible image previews.
- Wait for visual and application state.
- Preserve an inspectable action history.
- Validate behavior through repeatable Codex-parity computer-use tasks.
