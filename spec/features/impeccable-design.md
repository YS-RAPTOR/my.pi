# Impeccable Design

An Impeccable-based system helps agents create, critique, and improve visual interfaces using explicit design principles.

- Analyze the existing visual language before proposing changes.
- Generate and render independently identifiable variants for comparison.
- Support direct annotations and selective acceptance of each option.
- Critique typography, hierarchy, spacing, color, interaction, responsiveness, and accessibility.
- Preserve annotations and selection rationale in the review flow.
- Use `jordi9/pi-impeccable` as the primary implementation reference.
