# Browser Use

The browser tool attaches to a browser on the current Hyprland workspace for the current Pi session.

- Attach to an existing browser on that workspace when available.
- Otherwise open a browser there and attach to it.
- Keep the attachment until that browser closes.
- Navigate, manage tabs, follow links, upload, download, and capture pages.
- Inspect DOM, accessibility, console, requests, responses, headers, timing, and failures.
- Wait for page, visual, application, or network state.
- Preserve an inspectable action history.
- Require approval for authentication, transfers, destructive actions, and external submissions.
- Validate behavior through repeatable Codex-parity browser tasks.
