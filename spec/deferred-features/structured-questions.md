# Structured Questions

Agents and workflows can present durable structured questions instead of relying on plain text. Multiple requests may remain pending while users answer or defer them independently.

- Preserve accepted requests when a UI closes temporarily.
- Show deadlines, cancellation, and final outcome.
- Prevent duplicate answers from producing duplicate actions.
