# Workflow Recovery Preview

Before recovery, users can preview how workflow edits affect prior execution. The preview clearly identifies retained, invalidated, added, and removed work.

- Compare the executed and selected revisions.
- Mark calls that will replay or run again.
- Require confirmation before changed recovery begins.
