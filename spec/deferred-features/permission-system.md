# Permission System

Stratum provides one fail-closed policy service for parent agents, subagents, and workflows.

- Cover tools, paths, external directories, Bash, MCP, skills, and extension operations.
- Resolve policy against current identity and workspace.
- Produce allow, ask, deny, or error outcomes through durable HITL.
