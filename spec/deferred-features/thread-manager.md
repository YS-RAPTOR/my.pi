# Thread Manager

A thread manager owns durable development threads within a Herdr workspace and connects them to their Pi sessions and related work.

- Create, open, search, snooze, settle, and archive threads.
- Link threads to Pi sessions, side chats, subagents, workflows, reviews, and background shells.
- Keep thread state separate from Pi runtime state.
- Return new activity to its owning thread and unset settlement.
- Focus the relevant Agent tab when opening a thread.
