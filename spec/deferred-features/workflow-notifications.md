# Workflow Notifications

Development activity produces project-aware notifications outside Pi without requiring the user to watch the Agent tab.

- Cover agents, side chats, subagents, workflows, heartbeats, reviews, and background shells.
- Identify the Hyprland workspace, Herdr workspace, thread, and source activity.
- Update or deduplicate notifications as state changes.
- Provide relevant focus, answer, review, output, and dismissal actions.
- Focus the correct workspace and tab when opened.
- Suppress unnecessary notifications when the target is already visible.
