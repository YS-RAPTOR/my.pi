# Composable Workflows

Workflows compose agents through sequential and parallel calls, branches, loops, pipelines, phases, and dynamic fan-out or fan-in.

- Support reusable nested workflow definitions.
- Keep orchestration visible in the workflow graph.
- Route every agent call through DurableAgent.
