# Workflow Limits And Quality

Workflow runs can expose enforceable resource limits and explicit quality checks. Users can see why a run retried, selected one result, or stopped.

- Limit time, calls, tokens, cost, concurrency, and fan-out.
- Support verification, judging, repair, and best-of-N checks.
- Report the limit or gate behind every stop or retry.
