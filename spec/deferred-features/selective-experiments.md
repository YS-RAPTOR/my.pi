# Selective Experiments

Agents can produce isolated experiments whose results remain separately reviewable. Users and agents can accept selected changes without taking an entire experiment or result.

- Compare an experiment with the current project state.
- Select changes at a practical review granularity.
- Keep agent-selected changes attributable and reviewable.
- Never merge, push, or delete results automatically.
