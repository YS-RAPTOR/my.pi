# Replayable Workflows

Users can inspect a workflow and resume it after edits or disruption without blindly repeating compatible completed work. Each run identifies the workflow revision it executed.

- Show the workflow graph and completed calls.
- Replay only an unambiguous compatible prefix.
- Resume live execution at the first changed call.
