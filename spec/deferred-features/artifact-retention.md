# Artifact Retention

Deleting an agent or workflow lets users choose what happens to its implementation artifacts and history. Work is never silently destroyed as a side effect of cleanup.

- Choose retention for transcripts, logs, worktrees, and branches.
- Keep retained artifacts discoverable afterward.
